# Contributing

Read [AGENTS.md](AGENTS.md), the [module map](docs/architecture.md) and the
[development guide](docs/development.md). Keep each change focused on a concrete
behavior or maintenance improvement and include appropriate regression coverage.

Run `npm ci --ignore-scripts` and `npm run verify` before delivery. Update
documentation when paths or operating steps change. Describe the problem,
resulting behavior, validation and material remaining limitations in commits/PRs.
Follow the branch requested by the task; otherwise use a focused branch and PR.
